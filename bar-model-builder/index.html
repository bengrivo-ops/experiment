Why it is built this way Schema-based instruction teaches pupils to recognise the problem type and draw its structure. In a randomised trial with Grade 3 pupils with maths difficulties it beat the control (g = 0.46). Concreteness fading (counters, then bars, then equations) improved transfer. There is no trial of a bar model game yet, so this game itself still needs validating. Sources: Jitendra et al. · Fyfe, McNeil & Borjas · McNeil & Fyfe
